# Simplefy

<img src="assets/branding/simplefy-icon.png" alt="Simplefy" width="128" height="128">

**Just music. Just play.**<br>
**Your music. Your way.**

Простой музыкальный клиент [Jellyfin](https://jellyfin.org/) на Flutter с навигацией по настоящим папкам, редактируемой очередью и прослушиванием без сети.

Сейчас реализовано приложение для **iPhone, iOS 14+**. Android запланирован; Android-проекта в репозитории пока нет. Интерфейс — на русском языке. Проект активно развивается; публикация в App Store и Google Play готовится отдельно.

## Возможности

- Коллекции → папки → композиции, с сохранением серверной структуры. Поиск по именам файлов, исполнителям и названиям композиций.
- Одна очередь воспроизведения: добавление папок, плейлистов и треков, перестановка и удаление записей, последовательное и случайное воспроизведение.
- Серверные и локальные плейлисты. Сохранение очереди локально, «Сохранить как» и сохранение изменений в исходный серверный плейлист при наличии прав.
- Загрузка композиций, папок и плейлистов на устройство; удаление загрузок меняет только данные устройства.
- Импорт аудиофайлов и папок из приложения «Файлы» в дополнительную локальную библиотеку. Локальную музыку можно слушать без Jellyfin.
- Фоновое воспроизведение, системные команды гарнитуры и управление с экрана блокировки.
- Предзагрузка следующей композиции и восстановление очереди, позиции и последней открытой папки или плейлиста.
- Выравнивание громкости по метаданным Jellyfin, включённое по умолчанию. Доступны режимы композиции, альбома и выключено. При отсутствии метаданных громкость не меняется; анализ аудио и усиление тихих записей пока не реализованы.

Нажатие на композицию запускает её и заменяет очередь содержимым открытой папки или плейлиста. Долгое нажатие на элемент открывает меню действий. Правки очереди сохраняются в исходный плейлист только по явной команде пользователя.

## Сборка и запуск

Для iOS нужны macOS, Xcode с установленным iOS SDK и Flutter stable. Рабочее окружение проекта: Flutter 3.44.5, Dart 3.12.2, Xcode 26.3. Версии зависимостей зафиксированы в `pubspec.lock`.

```sh
git clone https://github.com/antontonkovkz/simplify.git
cd simplify
flutter pub get
flutter devices
flutter run -d <simulator-id>
```

Сборка для симулятора:

```sh
python3 tool/build_ios.py --variant public --simulator
```

Для физического iPhone настройте свою подпись:

```sh
cp ios/Flutter/Signing.example.xcconfig ios/Flutter/Signing.local.xcconfig
```

В `Signing.local.xcconfig` замените `YOUR_TEAM_ID` на идентификатор своей Apple Development Team. Этот файл исключён из Git. При необходимости измените Bundle Identifier в `ios/Runner.xcworkspace` на доступный вашему аккаунту. Затем:

```sh
python3 tool/build_ios.py --variant public
```

Публичная точка входа — `lib/main.dart`. В приложении укажите адрес собственного Jellyfin-сервера и войдите в свою учётную запись либо импортируйте локальную музыку. Тестовых учётных данных в репозитории нет. Пароль не сохраняется; сессия хранится в Keychain. Для выхода или смены сервера откройте настройки.

Необязательная персональная точка входа `lib/main_personal.dart` поддерживает начальную сессию через `BOOTSTRAP_SESSION`. Утилита сборки принимает приватные определения только из файла **вне проекта** с `--variant personal --definitions <file>`. Такие сборки содержат сессию и предназначены для личного использования. Публичная точка входа отклоняет непустой `BOOTSTRAP_SESSION`.

## Проверки

```sh
flutter analyze
flutter test
```

Сквозные проверки запускайте на отдельном симуляторе: они изменяют локальные данные тестового приложения. Например, автономный сценарий выравнивания громкости:

```sh
python3 tool/run_integration.py --device <simulator-id> --suite volume_normalization
```

Для серверных сценариев передайте `JELLYFIN_TEST_SERVER`, `JELLYFIN_TEST_USER`, `JELLYFIN_TEST_PASSWORD` через окружение или приватный файл вне проекта (`--credentials <file>`, ключи `TEST_SERVER`, `TEST_USERNAME`, `TEST_PASSWORD`). Все наборы последовательно запускаются через `--suite all`. Фоновые сценарии симулятора дополняются ручными проверками на iPhone.

## Структура кода

| Каталог | Назначение |
| --- | --- |
| `lib/domain` | Каталог, очередь и правила воспроизведения |
| `lib/application` | Сценарии приложения и интерфейсы внешних сервисов |
| `lib/infrastructure` | Jellyfin, аудио, загрузки, импорт и хранение |
| `lib/presentation` | Экраны, виджеты, навигация и тема |
| `ios` | Нативный проект и импорт из «Файлов» |
| `test`, `integration_test` | Автоматические проверки |
| `tool` | Инструменты сборки и проверок |

Исправления и предложения приветствуются через [Issues](https://github.com/antontonkovkz/simplify/issues) и pull requests. Перед отправкой изменений выполните анализатор и подходящие тесты; пароли, токены, параметры личной подписи и приватные конфигурации оставляйте вне репозитория.
